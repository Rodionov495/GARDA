Необходимо соблюдать корректную форму наименования для всех документов на всех объектах в целях повышения уровня культуры проектирования.

## Проектная документация.

Наименование томов проектной документации по шифру тома по договору и в соответствии с ПП 87





## Рабочая документация.

Наименование листов рабочей документации должно быть выполнено по следующей формуле:

**\[тип чертежа\{номер листа}\].\[шифр\].\[марка\].\[наименование листа\]**

### Тип чертежа

0XX – обложки и титульные листы, состав проекта, лист внесения изменений

1XX – общие данные, условно-графические обозначения

2XX – планы

3XX – схемы

4XX – разрезы, узлы

5XX – спецификации

6XX- прилагаемые документы (расчёты, техлисты, паспорта)



### Пример наименования

**207\.5703.СПС.План расстановки оборудования +1 эт. (оси 1-21)**

**207** –  тип документа – «план», и номер листа 7

**5703** – шифр проекта в соответствии со стадией по договору

**СПС** – марка тома по договору/ГПР

И далее наименование листа.

Наименования листа для марки необходимо стандартизировать.
