**Программы, используемые в компании:**

-  **Яндекс Мессенджер**: основное общение, чаты по объектам, групповые чаты по разным вопросам

-  **Яндекс Телемост/Zoom:** для онлайн общения с коллегами и по проектам

-  **Яндекс Трекер:** платформа для управления задачами по проектам

-  **Почта Outlook:** обмен заданиями, выдача разработанной документации, массовое информирование. Ведение календаря встреч

-  **Портал** **Avilex Conflux** <https://conflux.avilex.ru/>**:**  «знакомство» с коллегами

-  **Telegram:** для общения с коллегами, чей ТГ известен, групповые чаты по проектам

-  **MAX:** общение с коллегами, чей ТГ неизвестен, групповые чаты по проектам

-  **Gramax** <https://gramax.avilex.ru/Knowledge_Base> **:** база знаний. Место хранения инструкций, внутренних стандартов, шаблонов

-  **NextCluod** <https://ncloud.avilex.ru/>**:** «облако» для хранения и работы с файлами по проектам, внутренние папки отделов

-  **Signal** <https://docs.sgnl.pro/>**:** среда общих данных про проектам, хранение ИРД. Задания для смежных отделов выкладываются в папку «Обмен заданиями»

-  **Revit:** размещение семейств по системам, прокладка кабельных линий, увязка трасс лотков со смежниками. Подготовка планов для выдачи документации

-  **AutoCad:** для отрисовки схем подключения, структурных схем, выдачи задания смежникам (дублирование задания, выданного в Ревите)

-  **Word/Exel:** ТЧ, спецификации, кабельные журналы и прочие расчеты
