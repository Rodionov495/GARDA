## Зачем нужен модуль

**«Проверка карточек»** помогает найти проблемы оформления задач и записей времени: пропуски плановых данных, списания без комментариев, работу вне указанных дат и другие находки. Модуль не исправляет все проблемы автоматически.

## Что внутри

Выбор источника задач, прогресс и результаты, управление процессом, фильтры проблем, исключения с причиной. Для закрытых задач доступно подтверждаемое исправление остаточной оценки.

## Выбрать источник

По умолчанию проверяется **текущая выборка**: уникальные ключи уже загруженных задач. Это не все задачи организации.

Для другого охвата используйте поиск задач по доступным параметрам. **Исполнитель**, **автор задачи** и **автор записи времени** — разные роли; выбирайте нужный параметр под вопрос проверки.

1. Откройте модуль и выберите источник.
2. Для текущей выборки проверьте уже загруженный набор. Для поиска задайте доступные параметры.
3. Запустите проверку и следите за прогрессом и логом.
4. Просмотрите результаты, примените фильтр проблем.
5. Перейдите к задаче по ссылке с ключом: она откроется в новой вкладке.
6. Исправьте данные в пределах прав и повторите проверку.

При временном отборе доступны действия применения, сброса и восстановления согласно состоянию. Строка действий не обязана быть видимой постоянно.

## Примеры находок

- Записи трудозатрат без комментариев.
- Списания на Epic/Story. Эти часы при этом не исключаются из итогов отчёта.
- Незавершённая задача более суток в работе без списаний.
- Отсутствие начала, дедлайна или оценки.
- Работа вне указанных дат и особенности закрытых задач.

Различайте ошибки, предупреждения, информационные замечания и задания на заполнение по категории результата. Не каждая находка означает одинаковую степень проблемы. Отсутствие резолюции у незавершённой задачи само по себе не ошибка.

## Найти списания без комментария

Выберите **«Списания без комментария»**. Проверяется комментарий **записи трудозатрат**, а не переписка в карточке. Пустая строка и одни пробелы считаются отсутствием комментария.

Посмотрите число задач, записей и часов. Например, две записи на 2 и 3 часа в одной задаче — одна задача, две записи, пять часов. Откройте историю и дополните записи в пределах прав.

«Работал» — не пустое значение, но слабое объяснение работы. Автоматическая проверка пустоты не заменяет оценку содержания.

## Исключения и исправления

Если оформляете исключение, укажите причину, чтобы было понятно, почему находка не требует обычной доработки. Исключение не стирает исходные записи.

Для закрытой задачи при предложении исправить остаточную оценку проверьте задачу и предлагаемое изменение, затем подтвердите действие. Само обнаружение проблемы не означает, что оценка уже исправлена.

Результат ограничен правами, найденными задачами и успешно обработанными данными. При остановке или неполном поиске не считайте список исчерпывающим.
