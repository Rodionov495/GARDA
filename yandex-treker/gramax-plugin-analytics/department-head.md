## Посмотреть темп работы по объектам

1. Сначала откройте **«Дашборд»**.
2. В левой панели задайте период сравнения и проекты отдела.
3. Нажмите **«Загрузить»** и дождитесь результата.
4. Сравните динамику списаний по датам и объектам.
5. Для одного объекта выберите его и нажмите **«Применить фильтр»**.
6. После просмотра нажмите **«Сбросить временный фильтр»**.

Не сравнивайте объект с другим, если по одному из них загрузка неполная.

## Посмотреть календарные затраты группы

1. Сначала откройте модуль **«Трудозатраты»**.
2. В меню групп выберите свою группу или совместимые группы.
3. В левой панели задайте период и объекты, нажмите **«Загрузить»**.
4. Откройте **«Календарь»** и сравните часы по датам и участникам.

Меню не позволяет выбрать одновременно группы с общими сотрудниками. Чтобы сменить конфликтующую группу, сначала снимите ранее выбранную. Подробности — в статье [«Группы сотрудников»](./groups.md).

## Найти задачи, которые требуют больше всего времени

Откройте **«Трудозатраты» -> «Таблица»**, сгруппируйте записи по задачам и отсортируйте итоговые часы по убыванию, если текущий экран поддерживает итог по задаче. Если итог недоступен, не называйте крупнейшей одну запись: суммируйте записи задачи за выбранный период. Проверьте комментарии, оценку, изменения исходных данных и замечания. Большие затраты сами по себе не означают ошибку -- сначала выясните причину.

Временный фильтр применяется и снимается через верхнюю панель. Фильтры диаграммы с действием **«Только здесь»** не меняют таблицу.


## Повторить этот отчёт

Сохраните настройки как [представление](./saved-views.md). В следующий раз сначала откройте нужный модуль, восстановите настройки, проверьте даты и загрузите данные.

Для визуального сравнения затрат в модуле «Трудозатраты» используйте [гистограммы](./histograms.md).
