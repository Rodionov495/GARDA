## С чего начать

Для сводной картины используйте **«Дашборд»**, для записей команды — **«Трудозатраты»**, для пропусков и ошибок — **«Проверка карточек»**. Группы сотрудников настраиваются отдельно слева.

## Посмотреть затраты по объектам

1. Откройте **«Дашборд»**.
2. Справа задайте сопоставимый период, объекты и состав сотрудников в **«Загрузка и фильтрация»**.
3. Нажмите **«Загрузить»** и проверьте «Загружено».
4. Сравните динамику и распределение часов. Для одного объекта примените временный отбор.
5. После просмотра сбросьте отбор; вернуть его можно доступным действием восстановления.

Часы показывают трудозатраты, а не готовность результата. Для вывода о темпе сопоставьте их с выполненными задачами и изменениями объёма.

## Посмотреть календарь группы

Откройте **«Трудозатраты»**, выберите состав, задайте период справа и загрузите набор. Выберите **«Календарь»**: сравните дни, строки и итоги; откройте историю нужного дня. Настройка итогов через шестерёнку не меняет записи.

Группы могут пересекаться. Не складывайте их итоги без проверки состава; учитывайте ограничения конфликтного выбора меню. [Группы](groups.md).

## Найти самые затратные задачи

В таблице трудозатрат используйте группировку по задачам и сравните суммарные часы за один период. Одна большая запись не равнозначна самой затратной задаче: у другой может быть много небольших записей. Для визуального сравнения используйте [гистограмму](histograms.md).

Откройте карточку по ключу, проверьте содержание работы, исходные данные и замечания. Большие часы сами по себе не доказывают ошибку.

## Проверить полноту учёта

В **«Проверке карточек»** рассмотрите записи без комментариев, задачи в работе без списаний и пропуски плановых данных. Результат зависит от источника задач и полноты обработки. [Маршрут проверки](card-check.md).

Для повторного анализа сохраните [представление](saved-views.md).
