# Запрещенные действия в Revit

<note>

Соблюдение установленной технологии работы обязательно для всех участников проекта. Нарушение регламентов даже одним пользователем может усложнить совместную работу и создать проблемы для всей команды.

</note>

При разработке проекта в Revit необходимо соблюдать следующие требования:

## Запрещенные действия

1. Не допускайте к совместной работе в Revit сотрудников, не прошедших обучение Revit и не ознакомленных с действующими стандартами и регламентами работы.

2. Создавайте проект только на базе утвержденных шаблонов проекта.

3. Загружайте семейства в проект только из утвержденной библиотеки семейств. **Использовать семейства, полученные другим путем -- из Интернета, других проектов и иных источников -- запрещено.**

4. **Запрещено открывать файлы других групп или специальностей с созданием локальной копии.** При необходимости открыть такой файл используйте опцию **«Отсоединить от файла хранилища»**.

5. **Запрещено открывать файл хранилища напрямую и работать в нем.**

6. **Запрещено удалять любые файлы в общих папках.** Ненужные файлы следует переносить во временные или архивные папки.

7. **Запрещено перемещать «Базовую точку проекта» и «Точку съемки».** Положение данных точек должно быть закреплено при создании проекта.

8. Связанные файлы должны загружаться **«По общим координатам»**. Сразу после загрузки связанный файл следует **закрепить** и переместить в соответствующий рабочий набор.

9. **Запрещено менять название файла хранилища (ФХ) без ведома BIM-менеджера / BIM-координатора.**

10. **Запрещено менять содержимое файла общих параметров.**

11. **Запрещено создавать новые стили текста, размеры, марки, материалы и другие элементы оформления без согласования с BIM-менеджером / BIM-координатором.**

12. **Запрещено загружать DWG-файлы посредством импорта в проект.** DWG должен подключаться как связь. Путь связанного DWG-файла не должен вести на локальный компьютер. Для каждого проекта создается отдельная папка для файлов данного формата.

13. DWG вставляется **только на текущий вид**.

14. **Запрещено скрывать на виде отдельные элементы без использования фильтра.**

15. **Запрещено переопределять графику на виде для отдельного элемента.**

16. Цветовые области и области маскировки можно использовать **только после согласования с координатором**.

17. **Запрещено перебивать размеры**, за исключением случаев, где используются переменные значения.

18. **Запрещено чертить линиями аннотаций и 3D-линиями на видах и листах**, за исключением легенд и чертежных видов.

19. **Запрещено применять инструмент «Зеркало» к категориям, имеющим элементы ориентации «Лево/Право»**, например к окнам и дверям.

20. **Запрещено строить элементы модели по DWG-подложкам, выбирая линии подложки или привязываясь к ним.**

21. **Запрещено оставлять в модели неиспользуемые DWG-подложки.**

22. **Запрещено работать в чужом именном вспомогательном рабочем виде.**

23. **Запрещено перемещать согласованные оси, уровни и связанные модели.**

24. **Запрещено копировать связанные модели в проекте.**

25. **Запрещено удалять связанные модели и заново их загружать без предупреждения или разрешения BIM-менеджера / BIM-координатора.**

26. **Запрещено откреплять закрепленные элементы и не закреплять их обратно после редактирования.**

27. **Запрещено образмеривать элементы модели с привязкой к подгруженным моделям инженеров.** Требование относится к оформлению выпускаемых чертежей.

28. **Запрещено использовать скрипты из сторонних источников без предупреждения или разрешения BIM-менеджера / BIM-координатора.**

29. **Запрещено менять шаблоны видов, настроенные для оформления выпускаемой документации.**

30. Пользователь обязан **синхронизироваться перед окончанием рабочего дня и закрывать модель**. Также необходимо синхронизироваться каждый раз, когда пользователь покидает рабочее место.

31. **Запрещено копировать спецификации и элементы геометрии из других проектов.**

32. **Запрещено переносить на планах оформленные разрезы.**

33. **Запрещено менять стили объектов без согласования с BIM-менеджером / BIM-координатором.**

34. **Запрещено размещать аннотации, марки и текстовые примечания на листе.** Они должны находиться в пространстве вида. Исключение -- общие указания сверху над штампом.

35. **Запрещено запускать два сеанса одной модели одновременно.** Если это необходимо, второй файл следует открывать с отсоединением от ФХ -- при открытии установить флажок **«Отсоединить от хранилища»**.

36. **Запрещено переопределять существующие настройки экспорта при экспорте в DWG.** При необходимости следует создать новые настройки экспорта.

37. **Запрещено присоединять верх или основание стен к перекрытиям**, за исключением стен рампы и рассечек в ЛК.

38. **Запрещено создавать один контур архитектурного пола или потолка на несколько помещений.**

39. **Запрещено соединять стены различных типов между собой.**

40. **Запрещено оставлять присоединенными торцы колонн и пилонов, построенных инструментом «Стена».**

41. **Запрещено перетягивать концы 3D-осей после согласования их положения.**

42. **Запрещено подписывать виды инструментом «Текст».** Необходимо использовать типоразмер вида с отображением имени.

43. **Запрещено использовать аннотации для маркировки элементов.** Для маркировки необходимо использовать марки.

44. **Запрещено менять настройки печати без согласования с координатором.**

45. **Запрещено удалять в диспетчере проекта виды, относящиеся к планам зонирования, предварительно не удалив с них зоны.**
