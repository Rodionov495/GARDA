## 1\. Что нужно знать

<note type="info">

**Требование стандарта**

К видам, используемым в модели, должны быть применены шаблоны видов. Наименования шаблонов должны соответствовать принятой схеме.

</note>

-  Шаблон вида используется для единообразной настройки отображения планов, разрезов, 3D-видов, спецификаций и других видов Revit.

-  Проектировщик применяет утвержденный шаблон, соответствующий этапу, разделу и семейству вида.

-  Настройки, контролируемые шаблоном, изменяются через сам шаблон, а не индивидуально на каждом виде.

-  Виды для оформления документации, экспорта и проверок должны сохраняться в модели; неиспользуемые рабочие виды перед передачей модели удаляются.

<note>

**Важно**

Требования к именованию и итоговой проверке взяты из стандарта. Пошаговые действия в интерфейсе Revit приведены как практический порядок выполнения этих требований.

</note>

## 2\. Правило именования

**Схема имени:** (\<1>)\_\<2>\_\<3>\_(\<4>)

| **Блок**           | **Содержание**                              | **Пример** |
|--------------------|---------------------------------------------|------------|
| 1\. Код вида       | Назначение вида или проектный этап          | ПД         |
| 2\. Раздел проекта | Шифр раздела; указывается при необходимости | АР         |
| 3\. Семейство вида | Тип/семейство вида                          | ПЭ         |
| 4\. Имя вида       | Краткое назначение или содержание           | Кладочный  |

<note type="info">

**Пример по стандарту**

(ПД)\_АР_ПЭ\_(Кладочный)

</note>

## 4\. Как применить существующий шаблон

**1\. Выберите вид.** Откройте вид или выделите его в «Диспетчере проекта».

**2\. Откройте свойства вида.** В палитре «Свойства» найдите параметр «Шаблон вида».

**3\. Назначьте шаблон.** Выберите шаблон, соответствующий этапу, разделу и типу вида.

**4\. Проверьте результат.** Убедитесь, что отображение соответствует назначению вида и на виде не появились лишние категории, связи или аннотации.

**5\. Для нескольких одинаковых видов.** Допускается выделить несколько видов одного назначения в «Диспетчере проекта» и назначить им один шаблон одновременно.

<note>

**Не подбирайте шаблон только по похожему названию**

Проверяйте все блоки имени: код вида, раздел, семейство и назначение.

Выбор шаблона в свойствах вида

</note>

## 5\. Создание и редактирование шаблонов

<note type="lab">

Используйте существующие утвержденные шаблоны. Создание, удаление и массовое изменение общих шаблонов необходимо согласовывать с BIM-координатором проекта.

</note>

**Откройте управление шаблонами.** Вкладка «Вид» -> «Шаблоны видов» -> «Управление шаблонами видов».

**Выберите основу.** Создайте новый шаблон из корректно настроенного вида либо скопируйте близкий по назначению шаблон.

**Назовите по стандарту.** Используйте схему (\<код>)\_\<раздел>\_\<семейство>\_(\<имя>).

**Определите контролируемые параметры.** Отметьте только те настройки, которые должны быть одинаковыми на всех видах данного назначения.

**Проверьте на тестовом виде.** До массового применения убедитесь, что шаблон не скрывает необходимые элементы и не включает лишние.

| **Группа настроек** | **Что проверить**                                                       |
|---------------------|-------------------------------------------------------------------------|
| Графика             | Уровень детализации, визуальный стиль, видимость категорий.             |
| Фильтры             | Набор фильтров, порядок, видимость и переопределения.                   |
| Аннотации           | Нужные категории аннотаций и их отображение.                            |
| Связи и импорт      | Видимость связанных моделей и импортированных категорий.                |
| Параметры вида      | Масштаб, дисциплина, подрезка и другие настройки -- по назначению вида. |

Схема окна управления шаблонами видов

## 6\. Вид и шаблон для экспорта в Navisworks

<note>

**Обязательное требование**

Во всех моделях должен присутствовать 3D-вид с точным наименованием «Navisworks».

</note>

| **Настройка**       | **Требование** |
|---------------------|----------------|
| Уровень детализации | Высокий        |
| Визуальный стиль    | Заливка        |
| Связанные модели    | Скрыты         |
| Аннотации           | Скрыты         |
| DWG-подложки        | Скрыты         |
| Оси и уровни        | Скрыты         |

| **Настройка**                                       | **Требование** |
|-----------------------------------------------------|----------------|
| Аналитическая модель                                | Скрыта         |
| Линии, формы и осевые линии инженерных систем       | Скрыты         |
| Задания на отверстия и временные элементы           | Скрыты         |
| Подрезка вида                                       | Отключена      |
| Артефактные 3D-элементы, не участвующие в проверках | Скрыты         |

Контрольные настройки экспортного 3D-вида

## 7\. Запрещенные действия

<note type="danger">

**Запрещено стандартом проекта**

Оставлять виды, используемые в модели, без требуемых шаблонов; нарушать схему именования шаблонов; передавать модель без настроенного 3D-вида «Navisworks».

</note>

-  Переименовывать шаблон без соблюдения утвержденной схемы.

-  Изменять общий шаблон ради одного частного вида. Для исключительной ситуации согласуйте отдельный шаблон.

-  Назначать шаблон другого этапа, раздела или семейства вида только потому, что его отображение визуально похоже.

-  Удалять или массово изменять утвержденные шаблоны без согласования с BIM-координатором.

-  Использовать ручные настройки отдельных видов как замену общему шаблону.

-  Включать на экспортном виде связанные модели, аннотации, DWG-подложки, оси, уровни и временные элементы.

## 8\. Проверка перед передачей модели

| **Проверка**                                                    | **Результат**  |
|-----------------------------------------------------------------|----------------|
| К видам применены шаблоны                                       | Да / исправить |
| Имена шаблонов соответствуют схеме                              | Да / исправить |
| На видах документации применены шаблоны нужного этапа и раздела | Да / исправить |
| Неиспользуемые рабочие виды удалены                             | Да / исправить |
| В модели есть 3D-вид «Navisworks»                               | Да / исправить |
| Настройки вида «Navisworks» соответствуют требованиям           | Да / исправить |
